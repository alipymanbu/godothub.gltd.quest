以 1.0.8 版的界面为准，功能集中在五个模块；版本迭代较快，具体措辞以你手上的版本为准。

引擎

列出 Godot 3.x 与 4.x 各版本，走国内镜像下载与安装，同一台手机可共存多个版本，项目与引擎随时切换。

项目

资源

教程

中文图文教程按入门、进阶、实战分类，配代码案例；零基础照着顺序走，就能在手机上跑通第一个工程。

社区

浏览与发布开发经验、项目模板，找协作伙伴；社区每年还办一届 GodotHub Festival 开发大赛。

REALITY CHECK

上手机前，先认清这几条边界

这些约束来自引擎项目方对安卓编辑器的说明，与你从哪个入口安装无关——写清楚，免得预期错位。

  • EXP-01
    安卓编辑器仍属实验阶段。

    引擎项目方在安卓下载页明确标注 experimental，稳定度不如桌面版，重要工程建议桌面与手机各留一份。

  • KEY-02
    强烈建议外接键盘鼠标。

    编辑器 UI 尚未针对触屏适配，纯触屏写代码效率很低；配一套外接键鼠才算可用的工作环境。

  • C#-03
    C# / .NET 在安卓编辑器上不可用。

    引擎项目方注明安卓编辑器不含 C# 支持，需要 C# 的工程要回桌面端处理。

  • EXP-04
    导出安卓包有附加条件。

    走 Gradle 构建导出时，需要另装引擎项目方的 GABE（Godot Android Build Environment）配套应用；普通预设模板导出则用不到。

  • GPU-05
    渲染器建议选 Mobile 或 Compatibility。

    Forward+ 在部分手机上表现不佳；安卓设备上一般用 Mobile 或 Compatibility 渲染器新建工程。

ROADMAP

三步跑通第一条手机工程

装好 GodotHub

从网盘转存安装包并安装（约 25 MB），首次打开会停在首页，数据都是空的。

下载一个引擎版本

进引擎模块，选一个 4.x 稳定版下载安装；新开项目直接选最新稳定版即可。

新建 2D / 3D 工程

到项目模块新建工程、选好引擎版本，配一套外接键鼠，就能开始搭场景写脚本。

FAQ

动手前常问的几件事

GodotHub 就是 Godot 引擎本体吗？
不是。它是由中文社区搭建的平台应用，不修改、不发行引擎；引擎各版本的本体来自引擎项目方（godotengine.org）的发布，App 做的是镜像下载与统一管理。
用它需要额外的网络工具吗？
不需要。引擎与资源分发面向国内网络环境，正常网络直连即可；下载速度随地区与运营商波动，可换时段重试。
Godot 3.x 的老工程还能用吗？
可以。App 同时覆盖 3.x 与 4.x 的引擎版本，老工程导入后按它适配的版本切换引擎即可。
手机要留多少空间？
安装包本身约 25 MB；真正占空间的是后续下载的引擎版本（单个数百 MB）与工程文件，开工前留出几个 GB 余量比较稳妥。
资源中心的插件都能随便用吗？
以资源详情页标注的授权协议为准：标注可商用的可直接用，标注需授权的先联系作者；重要工程先备份，再试新插件。
